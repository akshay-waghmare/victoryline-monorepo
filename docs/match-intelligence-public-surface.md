# Match Intelligence surface boundary

The public Match Intelligence page is intentionally compact. It exposes the current match signal, score context, probability, visible shift, current explanation, and next watchpoint.

The following are product/model design notes, not public UI content:

- run-rate pressure and par-score module contracts;
- next-phase watchpoint rules;
- match-state and model-reason rationale templates;
- freshness proof and release/indexing policy;
- Spec 044 search and SSR release gates;
- operator-only or training-feature disclosure rules.

These notes remain in the component implementation and release/spec documentation, but should not be rendered as explanatory placeholder cards on the live page.
