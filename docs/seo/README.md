# Crickzen SEO workspace

This folder is the operating home for Crickzen SEO: evidence, keyword decisions, content briefs, and weekly reports. It supplements the product source of truth in `specs/044-cricket-decision-intent-acquisition/`; it does not authorize thin keyword pages.

## Scope

- Site: `https://www.crickzen.com`
- Primary acquisition market: India, English search
- Core product proposition: live cricket score first, followed by model-backed win probability and an explanation of what changed, why, and what matters next.
- Non-goals: betting, sure-win, astrology, or Dream11/tips positioning.

## Working folders

- `gsc/`: first-party Search Console exports or links and data notes.
- `keywords/`: scored clusters, exclusions, and surface assignments.
- `content/`: approved briefs for reusable hubs or explanations.
- `reports/`: weekly query-to-intelligence performance review.

## Operating rule

Every candidate keyword must map to one lifecycle, owning URL family, visible answer, event, and owned next step. A keyword variation alone never justifies a new URL.
