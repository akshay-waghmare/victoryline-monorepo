# Spec 055 — Lifecycle Authority and Rich SSR

One resolved lifecycle must drive match hubs, match SSR, metadata, `SportsEvent`, and sitemap eligibility. A source timeout is an availability error, not permission to publish a `200 index,follow` thin page. SSR may serve a retained rich snapshot; otherwise it returns a non-indexable `503`.

Acceptance: a Test at stumps cannot appear upcoming and completed; sitemap and hub use the owner lifecycle; no indexable response includes `temporarily loading`; a provider outage serves the last rich snapshot or `503`.
